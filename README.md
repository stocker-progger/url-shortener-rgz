# URL Shortener API (РГЗ)

RESTful API на Flask для создания коротких ссылок с кэшированием, лимитами и статистикой.

## Требования
- Python 3.10+
- pip

## Установка
```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate     # Windows

pip install -r requirements.txt
